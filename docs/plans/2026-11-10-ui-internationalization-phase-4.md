## Global constraints

- Support `zh-CN` and `en` with `en-NZ` display formats. Retain the existing loopback DEV preview, browser-local language lifecycle, original artwork and the Chinese default. Public builds stay Chinese even with a saved English preference. Enabling the switch, integrated release acceptance and performance decisions belong to Phase 5.
- Translate app-owned labels, enum presentations, warnings, errors, notices, field hints, placeholders, titles, tooltips, empty/loading states and accessible names. Preserve source file bytes, headings and values, filenames, descriptions, account/instrument/provider names, tags, notes, email addresses and redacted diagnostic payloads. Translate suggestions' surrounding copy; never translate a tag value saved or submitted by the app. Keep user-visible diagnostics separate from actionable UI errors.
- Render semantic descriptors from current language; preserve route/query, cache identity, drafts, file selection, original versions, pending operations, pagination, selected IDs, overlays and focus. Language changes must not cause reads, submissions, refreshes or replay. Existing blocking native prompts translate at invocation; browser-owned controls and beforeunload text follow the browser.
- Keep decimal-string spending values exact (including existing em dash and sign behavior), native currencies separate, date-only values unchanged in data and viewer-local timestamps distinct from Shanghai 06:00 business-day logic. Sorting, permissions, credentials, schema, calculations, retention, jobs and deployment configuration are outside scope.
- Use the existing `test` checkout and local synthetic fixtures. No shared-data writes, infrastructure changes or migrations; no issue, commit, push or deployment under this plan request.

## Review focus

| Failure mode | Evidence required |
| --- | --- |
| A previous build saved a preview without reason metadata | Task 3: reopen without parsing/upload; preserve row numbers, warnings count and blocking behavior with actionable localized guidance. |
| A commit response disappears after the server accepts the CSV | Task 3: identical explicit retry identity and no replay or request from switching language; recovered committed state has a translated result. |
| A reported tag has the same text as the application's untagged label | Task 2: use the null bucket identity, preserving the actual tag, counts and filter semantics. |
| A translated reset/permission error leaks a password, mislabels a stale edit, or encourages retry after unknown outcome | Task 4: error retranslation with fake secrets, unchanged revision and role, no disclosure or automatic retry. |
| A backup is delayed rather than failed, or a maintenance log page is empty with a cursor | Task 5: distinguish known status and permit explicit continuation without initiating it on a language change. |
